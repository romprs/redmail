# Почтовый клиент RED OS — прототип (Фаза 0)

Минимальный прототип из дорожной карты: окно на PySide6, подключение к
почтовому ящику по IMAP, список писем из INBOX. Критерий готовности Фазы 0 —
прототип открывает ящик по IMAP и рисует список писем на реальном RED OS 8;
эта версия проверена на Windows, проверка на RED OS — следующий шаг.

## Запуск

```bash
python -m venv .venv
.venv/Scripts/pip install -e .
.venv/Scripts/python -m redmail
```

В окне — кнопка «Подключиться…»: сервер, порт, логин, пароль. Для Gmail/Yandex
и т.п. нужен пароль приложения, а не основной пароль аккаунта.

## Тесты

```bash
.venv/Scripts/pip install pytest
.venv/Scripts/pytest
```

Тесты гоняют разбор IMAP ENVELOPE (тема в RFC2047, адрес отправителя,
пустой ящик) на подменённом клиенте — без реального сервера.
